1. Serial Connection

Checking for Voyager Link...

This page is served by the device over plain HTTP, so Chrome does not let it open serial ports itself. Voyager Link is a small Windows helper that runs in the system tray and connects this page to the USB port or to a paired Bluetooth serial port.

  1. Download Voyager Link while you have internet access, and run it (no install needed).
  2. If Windows SmartScreen warns about it, choose More info → Run anyway.
  3. If Chrome asks to let this page access apps on your device, choose Allow.

On Android, the Voyager Link app connects this page to the device over a USB OTG cable or Bluetooth.

  1. Install the Voyager Link app while you have internet access, open it and tap Start.
  2. For Bluetooth: switch Bluetooth serial on above, then pair with the device in Android's Bluetooth settings.
  3. If Chrome asks to let this page access apps on your device, choose Allow.
